# multisom-programmer-PCB

This is the printed circuit board (PCB) I worked on during my internship. It is a multi-SoM programmer board that is capable of programming 8 SoMs simultaneously rather than sequentially. I used OrCAD Capture and Cadence Allegro for this design. Figure 1 shows the initial design that I created of the board. Figure 2 shows an interposer board that I designed, which connects into a main programmer board that contains the programmer and voltage regulators.
